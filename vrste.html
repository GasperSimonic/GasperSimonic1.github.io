Vrste operacijskih sistemov

Operacijske sisteme lahko razdelimo glede na namen uporabe in vrsto naprav, na katerih delujejo. Med najbolj znane vrste spadajo namizni, mobilni, strežniški, vgrajeni in realnočasovni operacijski sistemi (Fernández Iglesias, 2023).

Namizni operacijskih sistemi

Namizni operacijski sistemi so namenjeni osebnim računalnikom in prenosnikom. Med najbolj znane spadajo Windows, macOS in Linux.

Windows razvija podjetje Microsoft in je najbolj razširjen operacijski sistem za osebne računalnike.

macOS uporablja podjetje Apple na računalnikih Mac,

Linux pa je odprtokodni sistem, ki se pogosto uporablja za programiranje in strežnike

(IBM, b.d.).

Mobilni operacijskih sistemi

Mobilni operacijski sistemi se uporabljajo na pametnih telefonih in tablicah. Najbolj razširjena sta Android in iOS. Android uporabljajo različni proizvajalci telefonov, medtem ko iOS razvija Apple za naprave iPhone (Fernández Iglesias, 2023).

Strežniški in posebni sistemi

Strežniški operacijski sistemi omogočajo delovanje spletnih strani, baz podatkov in omrežij. Najpogosteje se uporabljata Linux Server in Windows Server. Ti sistemi so prilagojeni za stabilno delovanje, varnost in delo z velikim številom uporabnikov (IBM, b.d.).

Vgrajeni operacijski sistemi

Vgrajeni operacijski sistemi se uporabljajo v napravah, kot so avtomobili, televizorji, medicinske naprave in gospodinjski aparati. Namenjeni so posebnim nalogam in pogosto delujejo z omejenimi strojnih viri (Fakulteta za računalništvo in informatiko Univerze v Ljubljani, b.d.).

Realnočasovni operacijski sistemi

Realnočasovni operacijski sistemi (RTOS) se uporabljajo tam, kjer je pomemben zelo hiter odziv sistema. Najdemo jih v industrijskih robotih, letalih, nadzornih sistemih in medicinskih napravah (Fernández Iglesias, 2023).
